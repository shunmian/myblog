## Troubleshooting

**Blog not updating after push?**
- GitHub Pages can take 1-5 minutes to update
- Clear browser cache (Cmd+Shift+R on Mac)
- Check Actions tab on GitHub for build status

**Want to make edits?**
- Run `myblog` locally to test changes
- Push to gh-pages when ready
- Use `/validate-posts` before committing

**Need to rollback?**
- Check git history: `git log --oneline`
- Reset if needed: `git reset --hard [commit]`
- Redeploy: `git push origin gh-pages`

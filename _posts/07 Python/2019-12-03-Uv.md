## 1 Install ##

```
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh
```

- init: `uv init`
- add dependancy: `uv add <package>`
- create uv.lock: `uv lock`
- recover from uv.lock: `uv sync`
- use chinese mirror, in `~/.config/uv/uv.tomal`, add
```
[[index]]
url = "https://pypi.tuna.tsinghua.edu.cn/simple/"
default = true
```

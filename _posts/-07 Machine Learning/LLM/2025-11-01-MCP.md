# MCP & AI Agents Learning Path

## Video Course Rankings (Top 3)

1.  **MCP: Build Rich-Context AI Apps with Anthropic** (DeepLearning.AI)
    - *Key Features:* Created with Anthropic, most authoritative, practical server/client building
    - *Link:* https://www.deeplearning.ai/short-courses/mcp-build-rich-context-ai-apps-with-anthropic/

2.  **Model Context Protocol (MCP) Course** (Hugging Face)
    - *Key Features:* Free with certificate, modular learning, community-driven
    - *Link:* https://huggingface.co/learn/mcp-course/unit0/introduction

3.  **MCP Complete Guide - Build and Connect Tools for LLMs** (Packt)
    - *Key Features:* Most comprehensive (7.5 hours), covers deployment and advanced projects
    - *Link:* https://www.packtpub.com/en-pl/product/mcp-complete-guide-build-and-connect-tools-for-llms-9781806384136


## Udemy MCP Courses

1.  **MCP Masterclass: Complete Guide to MCP in Python [2025]** (Udemy)
    - *Key Features:* A thorough, non-bootcamp-style course covering MCP theory, architecture, server/client building, and real-world applications. Ideal for going from beginner to expert with Python focus.
    - *Link:* Udemy Link

2.  **MCP Crash Course: Complete Model Context Protocol in a Day** (Udemy)
    - *Key Features:* Fast-paced intro to building, connecting, and deploying MCP servers/clients for LLM apps. Assumes Python proficiency; great for quick mastery of tools and resources.
    - *Link:* Udemy Link

3.  **MCP Bootcamp: Build, Deploy & Secure Model Context Protocol** (Udemy)
    - *Key Features:* Hands-on bootcamp for implementing, publishing, and securing MCP in production. Starts from basics, includes Python examples, and covers Anthropic's 2024 standard.
    - *Link:* Udemy Link

## Learning Path (Short)
- Short answer: Start with an Agentic AI course first → then take an MCP Masterclass. MCP is a tool/protocol that makes sense after you know what agents are solving.
- Week 1: Finish an Agentic AI course and build 1 mini agent (e.g., Web Search + Calculator).
- Week 2: MCP theory and build 1 MCP server (Python/Node).
- Week 3: Swap one agent’s tool-calling to MCP and test end-to-end.
- Week 4: Deploy and secure (OAuth, rate limits).

Start with MCP first only if:
- You already built LangChain/LlamaIndex agents.
- You work with Anthropic/Claude daily.
- You only need an MCP server for an existing agent.

Analogy: Learn to drive a car (Agentic AI) → then learn how the USB-C port works (MCP).
